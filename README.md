# Gestão de Jardinagem — MVP v1.0

Aplicação web/PWA local-first para gestão pessoal de trabalhos de jardinagem.

## Incluído nesta primeira construção
- Dashboard
- Calendário semanal com grelha horária
- Clientes
- Trabalhos
- Estados de trabalho
- Temporizador/sessões
- Regra de uma sessão ativa
- Trabalhos multi-sessão
- Reagendamento e histórico
- Reagendamento de continuação
- Preço à hora/preço fixo
- Preço mínimo
- Custos
- Pagamentos (estrutura inicial)
- Orçamentos (estrutura inicial + impressão/PDF via navegador)
- Fotografias comprimidas localmente
- Equipamentos
- Definições
- Backup JSON
- Restauro JSON
- Exportação CSV
- Service Worker/PWA

## Dados
Os dados são guardados no armazenamento local do navegador. Não existe backend nesta versão.

## GitHub Pages
1. Criar um repositório no GitHub.
2. Copiar o conteúdo desta pasta para a raiz do repositório.
3. Ativar GitHub Pages em Settings > Pages.
4. Escolher a branch principal e a pasta `/root`.
5. Abrir o endereço Pages no iPhone e, no Safari, adicionar ao ecrã principal.

## Nota
Esta é uma primeira versão funcional/MVP. Antes de utilização real, recomenda-se testar backup/restauro, temporizador, fotografias e comportamento no iPhone.
