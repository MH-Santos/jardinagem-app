# Jardim-app — V4

Web app/PWA local-first para gestão de trabalhos de jardinagem.

## V4 — correções desta ronda
- Definições independentes por quadro, com gravação que fecha a edição.
- Logo da empresa sem perder alterações ainda não gravadas e opção de remover.
- Edição/eliminação de equipamentos.
- Pesquisa de clientes com resultados apenas durante a pesquisa e seleção que fica aplicada no campo.
- Estimativa de horas vazia por defeito nos novos trabalhos.
- Validação robusta das datas/horas das partes dos trabalhos.
- Calendário Dia/Semana/Mês e correcção do cálculo do horário fora de funcionamento.
- Fotografias de orçamento com opção de remoção.
- Pagamentos por cliente e trabalho.

## Publicação no GitHub Pages
1. Extrair os ficheiros.
2. Colocar os ficheiros na raiz do repositório GitHub.
3. Fazer Commit changes.
4. Confirmar em Settings → Pages que está activo Deploy from branch / main / root.

Os dados da app são guardados localmente no dispositivo. O GitHub aloja apenas os ficheiros da aplicação.
