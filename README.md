# Gestão de Jardinagem — V3

PWA local-first para gestão de clientes, trabalhos, calendário, custos, pagamentos, orçamentos, fotografias, equipamentos e backups.

## Publicação no GitHub Pages
1. Criar/abrir o repositório no GitHub.
2. Colocar estes ficheiros na raiz do repositório.
3. Em **Settings → Pages**, selecionar **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Abrir o endereço GitHub Pages apresentado pelo GitHub.
5. No iPhone, abrir no Safari e, se desejado, usar **Partilhar → Adicionar ao ecrã principal**.

## Atualização
Substituir os ficheiros da versão anterior pelos desta versão e fazer **Commit changes**. O Service Worker utiliza uma nova versão de cache para forçar a atualização da aplicação.

## Dados
Os dados são armazenados localmente no dispositivo/browser. Fazer regularmente **backup JSON** e guardar o ficheiro fora do dispositivo.

## Nota
Esta é uma versão de testes funcional. Antes de utilização real, testar no iPhone todos os fluxos de clientes, trabalhos, sessões, custos, pagamentos, orçamentos e backups.
